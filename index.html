Overview

In this homework we implemented bezier curves and surfaces by using the De Casteljau subdivision algorithm and triangle meshes via the half edge data structure.

Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

De Casteljau's algorithm is a recursive algorithm that allows you to generate every point along a bezier curve. Start off with n points, use a variable t to place intermediate control points between each pair. Recursively repeat this process until you have only a single point. This point will lie on the final bezier curve. We implemented this by using linear interpolation between every pair of points using a for loop, based on a given t.

Part 2: Bezier surfaces with separable 1D de Casteljau

For bezier surfaces, instead of n control points we are given an n x n grid of control points. We can use De Casteljau to find the final control point for each for each group of control points n using a parameter u, resulting in n control points we can think of this as a bezier curve that lies along our surface. Then with all these n control points, we can use De Casteljau again to find a final point in 3D space using a parameter v.

Section II: Triangle Meshes and Half-Edge Data Structure

Part 3: Area-weighted vertex normals

To begin, we know that we can separate a triangle into two vectors (a to b and a to c). Using this we can compute the cross product to compute a normal. To actually do this we start with a given vertex and its associated half edge. Compute the normal for the triangle associated with the half edge and add it to a result vector. Then move on to the next related half edge by getting this half edge's twin and the next edge. We repeat this process until we end up at the same edge we started at. From here we can find the unit vector of the result vector and return it.

Part 4: Edge flip

We implemented edge flip by have some boundary checks that the current edge we're flipping is not a boundary edge (if so we return the edge without doing anything). Then we reassigned the current edge's vertices to be the flipped ones. Following this we updated all the next pointers manually such that they match the new flipped edge. In addition, this required updating the origins of the half edges, the faces, face half edges, and vertex half edges. To debug, we had a hand drawn diagram of the operation and how the edges, faces, and vertices would be reassigned. Then we opened up the teapot and tried flipped edges and played around with clicking the new edge and its half edges and visually fixed the errors we saw in the operation like a missing face.

Part 6: Loop subdivision for mesh upsampling

We mostly just followed the given instructions. To begin we iterated over all vertices (for the time being ignoring boundary vertices) in the mesh and stored a sum of the positions of all connected vertices (vertex -> half edge -> twin -> vertex -> position) we then plugged this into the forumla and stored it in the new position parameter.

That being for a vertex of degree n where u is 3/16 if n is 3 and 3/8n otherwise: \((1-n\cdot u) \cdot \text{original_position} + u \cdot \text{neighbor_position_sum}\).

Then we calculated the new vertex positions using the given formulas and stored them in each existing edge (for now also ignoring boundaries).

That being for two triangles sharing an edge A, B and points C, D: \(3/8 \cdot (A+B) + 1/8 \cdot (C+D)\).

Following this we just split every edge using the function we created in the last part, making sure to mark new vertices and set their positions.

Next, we flipped every new edge that connected an old to a new vertex.

Finally, we updated every vertex with the position stored in their new position parameter.

Upscaling naturally heavily smooths out sharp corners and such due to the fact that we're calculating new vertex positions based on neighboring vertices. If you split edges that lead to corners repeatedly before upsampling you preserve the "corner-ness" much more.
Along these lines due to the fact that our cube mesh is split along a single diagonal upon an upsample the mesh becomes very asymetric (corner vertices will have vastly different new positions due to which vertices they're connected to via an edge). We can mitigate this by splitting the edge that runs across every face before upsampling.
