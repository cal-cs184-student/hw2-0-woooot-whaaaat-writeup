Overview

In this homework we implemented bezier curves and surfaces by using the Casteljau subdivision algorithm and triangle meshes via the half edge data structure. For the bezier curves we learned how this algorithm which applies recursively on a set of control points leads to the final point to draw the bezier curve from and how to apply it across a mesh to create a bezier surface. For the triangle meshes, we learned how the half edge data structure and its functions of flipping and spliting triangles leads to triangle subdivision.

Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

Casteljau's algorithm is a recursive algorithm that for n points it creates n-1 intermediate control points using linear interpolation based on a parameter between every pair of 2 points to create a new point. We implemented it by using a for loop between every pair of points in the given n points and used the lerp function with parameter t to generate a new n-1 set of intermediate control points which we push each one to a list.

Part 2: Bezier surfaces with separable 1D de Casteljau

For bezier surfaces, we are given an n x n grid of control points. We found the bezier curve control point for each 1xn row of control points for each bezier curve row of control points that composes of the surface by parameter u. Then with all these new control points, we use evaluate 1D to then get the singular control point for the surface using the parameter v.

Part 4: Edge flip

We implemented edge flip by have some boundary checks taht the current edge we're flipping is not a boundary edge. Then we reassigned the current edge's vertices to be the flipped ones. Following this we updated lal the next pointers manually such that they match the new flipped edge. In addition this required updating the origins of the half edges, the faces, face half edges, and vertex half edges. To debug, we had a handwritten diagram of the operation and how the edges, faces, and vertices would be reassigned. Then we opened up the teapot and tried flipped edges and played around with clicking the new edge and its half edges and visually fixed the errors we saw in the operation like a missing face.
